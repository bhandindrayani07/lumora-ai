
# Lumora — AI Study Companion

**Learn smarter. Remember longer.**

Lumora is a student-focused AI study assistant designed to turn study notes into summaries, quizzes, and flashcards.

## Planned Features
- AI-generated study summaries
- Interactive quizzes and flashcards
- Study history
- Light and dark themes
- Responsive design

## Technologies
- HTML
- CSS
- JavaScript
- AI API integration (planned)

## Status
Project in development.
